# Tracking_Box_Video
Creates bounding boxes on video by tracking everything present in the footage. Implemented using Python.

Python 3.11 or higher is required (proper functionality is not guaranteed). The code uses the following libraries: moviepy 1.0.3, numpy, and OpenCV.

Command to install all required libraries:
`pip install moviepy==1.0.3 opencv-python numpy`

To create a video, rename your source video file to `input.mp4`, the resulting video will be saved as `output.mp4`. Then, run `start.bat`.

Settings for the boxes can be found within `main.py`.
